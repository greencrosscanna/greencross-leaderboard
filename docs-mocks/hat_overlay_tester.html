Reference notes

  • DiceBear viewBox: the rendered avatar SVG uses viewBox 0 0 264 280. Design your hat at the same viewBox so it scales naturally.
  • Head position: the head sits in the upper-center, roughly y=20–130 in the 280-unit space. Aim your hat's brim line for ~y=60–80.
  • Background: keep your SVG fully transparent — no background fill — so the green gradient puck shows through.
  • Color: use solid fills only (no external image refs). If you want a recolorable hat later, use a single fill="#2d5a3d" and Code can swap it dynamically via DOM attribute.
  • Open the SVG directly (link in panel 2) to right-click → Save As. Then open it in Figma/Illustrator to study the existing hat's geometry before designing your own.

How Code will use it

When your hat SVG is ready, drop it at src/avatar/hats/gc-cap.svg (or wherever in the repo) and tell Code. The render pipeline already handles the overlay pattern — a 2-layer puck with the DiceBear avatar (bald) on the base and your hat absolute-positioned on top. When the employee picks "Green Cross Cap" in the picker, the saved config sets top: '_none' + customHat: 'gcCap', and the render layer composes both.
